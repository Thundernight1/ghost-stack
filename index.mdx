Ghost-Stack Core is a Linux kernel-level security orchestration platform. It deploys cryptographically isolated department containers behind a four-layer eBPF deception firewall, so unauthorized scanners cannot determine that your host exists.

All enforcement runs inside the kernel. There is no userspace daemon you can tamper with, disable, or bypass.

## Why Ghost-Stack

Traditional firewalls answer probes. They send `RST`, `ICMP unreachable`, or a TCP timeout — every response is signal that confirms your host is real. Ghost-Stack inverts that model: unauthorized packets are dropped silently at the NIC driver via XDP, before the kernel network stack ever sees them.
